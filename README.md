# INAES – Ice Nucleation Analysis eSoftware

**INAES** is a free open source software for Ice Nucleation data analysis.  
It enables the user to explore:

- Freezing Curves
- LOESS estimation of INP concentrations
- Metadata integration and correlation
- Boxplot and Spearman Analysis
- Export of results as PNG

## Installation

To install, download the `.dmg` file from the [Releases](https://github.com/lamesta/INAES-Ice-Nucleation-Analysis-eSoftware/releases) page and drag the INAES icon into your Applications folder.
